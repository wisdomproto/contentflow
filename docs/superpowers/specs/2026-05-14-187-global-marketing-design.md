## 1. 전략명 & 한 줄 요약

**"한국 본사 운영 + 현지 에이전시 핸드오프 — 4축 단계적 진출 (TH → VN → EN)"**

마케팅·상담은 한국 본사에서 통제, 클로징·진료는 현지 에이전시에 핸드오프. ContentFlow + dflo_0.1 자산을 한 팀이 레버리지해서 운영. Phase별 채널 진화(유료 → 오가닉)로 단기 검증 + 장기 자산 동시 구축.

## 2. 핵심 가설

1. **운영 분리의 효율**: 한국 본사가 마케팅·상담을 통제하면 다국어 콘텐츠 자동화·CRM·KPI 가시성 ↑. 현지 진료는 에이전시가 맡아 의료법·현지 운영 부담 ↓.
2. **dflo_0.1 콘텐츠 source**: 백엔드 환자 치료 사례 데이터를 자동 익명화·다국어 변환해 마케팅 콘텐츠 source로 활용. YMYL E-E-A-T의 핵심 무기.
3. **DFlo 앱 = funnel의 핵심**: 상담 후 환자 2그룹(상담만 / 본격 치료)을 앱이 관리. 그룹 A는 계속 nurture, 그룹 B는 현지 진료 + 앱 관리.
4. **모델 표준화 → 복제**: TH에서 검증된 모델을 VN에 복제 → EN에 본격 적용. 후속 시장 속도 ↑.

## 4. 글로벌 환자 Funnel (핵심 다이어그램)

```
[글로벌 광고/오가닉]
        ↓
[각국 홈페이지 (다국어 서브디렉토리)]
        ↓
[상담 SNS 클릭]
  TH: Line + Messenger
  VN: Zalo + Messenger
  EN: WhatsApp + Messenger
  KR: 카톡
        ↓
┌───────────────────────────────────────┐
│  🇰🇷 한국 본사 응대 구간 (핵심 운영)    │
│  - 챗봇 1차 (각국 언어 자동)            │
│  - 사람 응대 (한국 본사, 각국 언어)     │
│  - CRM 태깅 (Supabase leads)           │
└───────────────────────────────────────┘
        ↓
[유료 상담 (한국 본사) + DFlo 앱 가입]
        ↓
   ┌─────────────────────────┐
   │                         │
   ↓                         ↓
[그룹 A: 상담만]          [그룹 B: 본격 치료 결정]
- 본격 치료 미시작           - 진료 개시 결정
- 앱 콘텐츠 + 리타게팅        ↓
- nurture 마케팅 지속      [🌏 현지 에이전시 핸드오프]
- 그룹 B로 전환 목표         - 클로징
                            - 현지 진료
                            - 의료법 컴플라이언스 처리
                              ↓
                            [현지 진료 + DFlo 앱 관리]
                              ↑
                            [한국 본사 supervision]
                            - 진료 프로토콜 표준화
                            - 데이터 모니터링
                            - 환자 만족도 관리
```

**환자 lifecycle 핵심 변수**:
- 그룹 A → 그룹 B **전환율** (nurture marketing의 성공 지표)
- 현지 에이전시 **핸드오프 conversion** (한국 상담 → 현지 진료 전환)
- DFlo 앱 **engagement** (양 그룹 retention)

## 5. 운영 모델 — 한국 vs 현지 에이전시 분리

| DFlo 앱 운영 | ✅ 전체 supervision | (현지 진료 환자만 사용) |

## 9. 공유 자산 구조

### 도메인 (다국어 SEO 시너지)

```
example.com/
  ├─ /ko/   한국어, 본진
  ├─ /en/   영어, 4시장 공통
  ├─ /th/   태국어
```

### 콘텐츠 source (자동 파이프)

```
1. dflo_0.1 백엔드 환자 치료 사례 데이터
   ├─ 익명화 + 의료법 컴플라이언스 처리
   ├─ ContentFlow 콘텐츠 변환 (사례 시리즈, 카드)
   └─ AI 다국어 번역 → 현지 의료 검토

2. 채용현 원장 책 + 진료 경험
   ├─ 챕터별 콘텐츠화
   └─ 동일 파이프

3. 박미정 책 등 외부 참고서
   └─ 요약·재구성

4. 환자 후기 필사 자료
   └─ 카드·인터뷰 영상 (의료법 익명화)
```

→ 8개 언어 자산 (ko/en/th/vi/ja/zh/ms/id) ContentFlow 인프라 활용.
